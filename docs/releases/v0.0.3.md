## What's Changed

This release adds private-conversation calendars and scheduled tasks, improves live updates and room switching, and gives agents consistent inbox and history tools.

### Features & Improvements

- Schedule one-time, daily, or weekly tasks in private conversations, through chat or a form. Manage them in day, week, and month calendars or a separate task list, and review execution history and reports in the original conversation. The TeamX service must be running for tasks to execute.
- Receive live message and state updates through SSE. Returning from an offline or background page catches up on changes while preserving the current draft and reading position.
- Switch between rooms with less waiting, using cached recent views and reduced repeated loading.
- Let agents read room messages, events, and platform notifications through consistent inbox tools. A shared GitLab project inbox lets selected team members read the same saved notifications with independent progress.
- Let agents revisit retained text and images through unified read-only history tools, including inputs already consumed, without marking them as new work.
- Choose an existing server directory for each member. Serial rooms can share a directory, while parallel rooms require non-overlapping directories; external files remain separately managed and backed up.
- Configure platform notifications more directly from member settings, with clearer source choices and notification controls.
- Open message images in a preview with zoom, rotation, and download controls.
- See the active instance home and any separate data or team-template locations in settings, with consistent paths for new personal installations.

### Bug Fixes

- Automatically recover enabled agents from eligible session incompatibilities or backend-state failures once prior execution is confirmed stopped. Manually paused agents remain paused, and unknown external actions still require verification.
- Fixed GitLab notifications remaining paused after the original account is successfully reauthorized, preserving the original start time, progress, and backlog.
- Fixed unrelated setting changes causing conflicts when saving tool bindings, notification settings, or long-term rules; checks now apply to the target being edited.
- Fixed conversation deletion being blocked by ordinary model-snapshot files, and made deletion progress and retry status clearer.
- Fixed human mention labels and unnecessary mentions in direct conversations; the human participant also appears in room membership.
- Fixed supported inline formatting being displayed as literal HTML in messages.
- Fixed rule-save feedback after failures or conflicts, keeping the draft available while the latest saved rule is reread.
- Fixed temporary error banners appearing before settings finish loading.
- Fixed the welcome screen flashing while an empty conversation is loading.
- Fixed Lark chat names disappearing from selectors after search or selection changes.

### Upgrade Notes

- Legacy room input data is converted automatically at startup. Keep a consistent instance backup before upgrading; after conversion, rollback requires restoring the matching backup rather than switching only the executable.
- Legacy subscriptions that posted notifications directly into conversations stop collecting and delivering. Reconfigure the source in a member's Platform settings or a shared GitLab project inbox. Existing conversation messages remain, but pending legacy notifications are not transferred and attachments tied to retired subscriptions may no longer load.

## 更新内容

本次发布新增私信日历与定时任务，改善实时更新和房间切换，并为 Agent 提供统一的收件与历史读取工具。

### 功能与优化

- 在私信中通过对话或表单创建一次性、每天或每周任务，使用日、周、月日历及独立任务列表管理安排，在原私信查看执行历史和报告。任务执行需要 TeamX 服务保持运行。
- 通过 SSE 实时接收消息和状态更新；页面从离线或后台恢复后补读变化，保留当前草稿和阅读位置。
- 通过缓存近期会话视图、减少重复加载，降低房间切换的等待。
- 让 Agent 通过统一收件工具读取房间消息、事件和平台通知；共享 GitLab 项目收件箱支持所选团队成员读取同一份已保存通知，并分别记录进度。
- 让 Agent 通过统一的只读历史工具回看保留的文字和图片，包括已消费输入，不将其重新标记为新任务。
- 为成员选择服务端已有目录；串行房间可共用目录，并行房间要求目录互不重叠。外部文件仍需单独管理和备份。
- 在成员设置中更直接地配置平台通知，使用更清晰的来源选择和通知开关。
- 点击消息图片打开带缩放、旋转和下载控件的预览。
- 在设置中查看当前实例主目录及单独配置的数据、团队模板位置，新个人安装采用统一的目录约定。

### Bug 修复

- 对已启用的 Agent，在确认原执行结束后自动恢复符合条件的会话不兼容或后端状态故障。手动暂停的成员保持暂停，结果未知的外部动作仍需先核实。
- 修复原账号重新授权成功后 GitLab 通知仍暂停的问题，恢复时保留原接收起点、进度和积压。
- 修复无关设置变更导致工具绑定、通知配置或长期规则保存冲突的问题，校验针对当前修改的目标进行。
- 修复普通模型快照文件阻塞会话删除的问题，并明确展示删除进度和重试状态。
- 修复人类用户的提及显示及私信中不必要的提及，并在房间成员中展示人类参与者。
- 修复受支持的行内格式在消息中显示为 HTML 原文的问题。
- 修复规则保存失败或冲突时的反馈，在重新读取最新规则时保留草稿。
- 修复设置尚未加载完成时短暂出现错误提示的问题。
- 修复空会话加载过程中欢迎界面闪烁的问题。
- 修复搜索或修改选择后 Lark 会话选择器丢失名称的问题。

### 升级注意事项

- 旧 Room 输入数据在启动时自动转换。升级前请保留整实例一致备份；转换后如需回退，应恢复匹配备份，不能只切回旧程序。
- 旧版直接向会话投递通知的订阅停止采集和投递，请在成员「平台」设置或共享 GitLab 项目收件箱中重新配置来源。已有会话消息保留，旧积压不转交，依赖停用订阅的附件可能无法继续加载。
