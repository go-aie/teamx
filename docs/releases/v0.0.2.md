## What's Changed

This release adds parallel collaboration within a room and improves conversation reading and navigation across desktop and mobile.

### Features & Improvements

- Run multiple agents concurrently in newly created parallel rooms, and use the Scion parallel-development template to split coding tasks across separate workspaces. Existing rooms retain their original scheduling mode; Scion requires its CLI to be installed separately.
- Browse direct conversations and team rooms in one list, with consistent headers, agent display names, and mention selection.
- Share unread-message and viewed-mention progress across devices. Locate unread mentions and new messages while keeping your place when reading older history.
- Navigate messages and agent profiles more easily on mobile, with refined touch actions, conversation-list controls, and chat styling.
- Set up installation and models through a simpler onboarding flow, with clearer getting-started documentation.

### Bug Fixes

- Fixed browser login sessions being lost on refresh, and focused the login input when authentication is needed.
- Fixed direct-conversation detail navigation so the return path is consistent with other conversation views.
- Prevented the GitLab CLI release banner from contaminating JSON output consumed by agents and scripts.
- Fixed installation-guide links in release archives so downloaded documentation points to accessible repository pages.

### Upgrade Notes

- Refresh the web UI after upgrading. Some older ordinary messages may appear unread again and are cleared when the conversation is successfully opened.

## 更新内容

本次发布新增房间内并行协作，并改进桌面与手机上的会话阅读和导航体验。

### 功能与优化

- 在新建的并行房间中同时运行多名 Agent，使用 Scion 并行开发模板在独立工作区分工编码。已有房间保留原调度模式；Scion CLI 需另行安装。
- 在统一列表中浏览私信和团队房间，使用一致的会话标题、Agent 显示名称和提及选择。
- 跨设备同步消息未读和提及查看进度，定位未查看的提及及新消息，翻阅较早历史时保留当前位置。
- 改进手机上的消息与助理详情导航，优化触摸操作、会话列表控件及聊天样式。
- 简化安装和模型配置流程，提供更清晰的入门文档。

### Bug 修复

- 修复刷新后浏览器登录状态丢失的问题，并在需要登录时自动聚焦输入框。
- 修复私信详情的导航行为，使返回路径与其他会话视图保持一致。
- 修复 GitLab CLI 版本提示混入 JSON 输出、影响 Agent 和脚本读取的问题。
- 修复发行归档中的安装指南链接，使下载后的文档能够跳转到可访问的仓库页面。

### 升级注意事项

- 升级后请刷新网页。部分较早的普通消息可能重新计入未读，成功打开对应会话后即可清除。
