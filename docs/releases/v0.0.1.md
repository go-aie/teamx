## What's Changed

TeamX's first public release brings AI teams and personal assistants into a shared web workspace.

### Features & Improvements

- Collaborate with role-based AI teams or talk to a personal assistant in direct conversations.
- Connect GitLab and Feishu/Lark to receive notifications and follow up on tasks.
- Manage models, agent activity, and long-term rules from the web UI.
- Install on macOS or Linux and access the service from desktop or mobile browsers.

---

## 更新内容

TeamX 首次公开发布，在统一的 Web 工作空间中提供 AI 团队协作与个人助理。
