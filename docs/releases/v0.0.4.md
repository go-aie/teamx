## What's Changed

This release adds conversation image attachments, managed image sharing to Lark and GitLab, workspace file previews, and simpler service upgrades.

### Features & Improvements

- Attach images to private conversations and team rooms by choosing files, pasting, or dragging them in. Preview images before sending and restore uploaded attachments with conversation drafts. Supports PNG, JPEG, and WebP; defaults are up to 4 images per message, 2 MiB each and 4 MiB total, subject to server limits.
- Ask agents to send retained conversation images, with optional text, to your Lark self-chat or one supported internal group using the bound user account. Requires the relevant tool permissions, image upload authorization, and verified destination; sending currently requires a macOS server. Ordinary message replies remain text-only.
- Ask agents to post images and optional text as a GitLab merge request comment or reply to an exact discussion. Provide a complete HTTPS MR or discussion link on the bound account's instance; agents verify the target before posting. Image sending requires a direct human instruction and uses retained human-uploaded images from the current conversation, up to 4 images, 2 MiB each and 4 MiB total. Unknown results are checked through the original receipt before another send.
- Browse member workspaces from the conversation, preview Markdown, text, and supported images, and download files. Open recognized workspace paths in messages directly in the file viewer, within the allowed workspace boundaries.
- Open files, calendar, and settings through a unified conversation menu. Pin desktop shortcuts to suit your workflow, and use consistent expandable panels and return navigation across desktop and narrow screens.
- Use responsive day, week or multi-day, and month calendars, with touch navigation and remembered view preferences. Mobile time views support horizontal date browsing while retaining the selected time position.
- Upgrade an installed service with `teamx service upgrade`, or select a version or local archive. Online upgrades download and verify the matching standard package, create a consistent backup, and restart the service; an already-current installation exits without downloading or stopping. View recent or streaming logs with `teamx service logs`.
- Build custom TeamX entrypoints by explicitly composing built-in platforms, external executable tools, and notification sources. Members still require the usual bindings and permissions; composition does not yet provide hot loading or binary size reduction.
- Give agents more focused command help, tool guidance, and input context, with simpler skill loading and Lark read workflows.

### Bug Fixes

- Fixed calendar scrolling, date navigation, and current-time indicator behavior, including preserving position while refreshing or changing views.
- Fixed bare links absorbing adjacent Chinese punctuation and restored supported historical HTML links in conversation messages.

### Upgrade Notes

- If the installed CLI does not yet support online upgrades, run `curl -fsSL https://github.com/go-aie/teamx/releases/download/v0.0.4/install.sh | bash -s -- --upgrade`. Add the original custom installation paths when applicable. Linux service commands require sudo; macOS commands do not.
- Re-running the ordinary installer now identifies an existing installation before downloading the application package and shows the upgrade entrypoint. Upgrade failures report the completed steps, backup location, and recovery commands; retain the consistent backup when recovering.

## 更新内容

本次发布新增会话图片附件、飞书与 GitLab 托管图文发送、工作区文件预览，并简化常驻服务升级。

### 功能与优化

- 在私信和团队房间中通过选择文件、粘贴或拖拽添加图片，发送前可预览，已上传附件随会话草稿恢复。支持 PNG、JPEG、WebP；默认每条最多 4 张、单张 2 MiB、合计 4 MiB，实际以服务端限制为准。
- 让 Agent 使用已绑定的飞书用户账号，将当前会话保留的图片和可选说明发送到本人自聊或准确的单个受支持内部群。需要相应工具许可、图片上传授权及目标核验；发送当前要求 macOS 服务端。普通消息回复仍仅支持文字。
- 让 Agent 将图片和可选文字发布为 GitLab MR 评论或回复准确讨论。可直接提供绑定账号同实例的完整 HTTPS MR／讨论链接，核实目标后再发布。图片外发需要人类直接明确要求，使用当前会话保留的人类上传原图，每条最多 4 张、单张 2 MiB、合计 4 MiB；结果未知时先查询原动作回执再决定是否重发。
- 在会话中浏览成员工作目录，预览 Markdown、文本和支持的图片并下载文件；消息中识别出的工作区路径可直接打开文件查看器，访问限制在允许的工作区范围内。
- 通过统一会话菜单打开文件、日历和设置，按需固定桌面快捷入口；桌面和窄屏采用一致的可展开面板与返回导航。
- 使用适配屏幕的日、周／多日和月日历，支持触屏导航并记住视图偏好；手机时间视图可横向浏览日期，同时保留所选时间位置。
- 使用 `teamx service upgrade` 升级已有服务，也可指定版本或本地归档。联网升级下载并校验对应 standard 包、创建一致备份并重启；已是目标版本时不下载、不停服。使用 `teamx service logs` 查看近期日志或持续跟踪。
- 通过显式组合内置平台、外部可执行工具及通知来源构建自定义 TeamX 入口。成员仍需按原规则绑定并授权；当前不提供热加载或二进制体积裁剪。
- 为 Agent 提供更聚焦的命令帮助、工具指导和输入上下文，简化技能加载与飞书读取流程。

### Bug 修复

- 修复日历滚动、日期导航和当前时间线行为，改善刷新及切换视图时的位置保持。
- 修复裸链接误吞相邻中文标点的问题，并恢复会话中受支持的历史 HTML 链接显示。

### 升级注意事项

- 已安装的 CLI 尚不支持联网升级时，执行 `curl -fsSL https://github.com/go-aie/teamx/releases/download/v0.0.4/install.sh | bash -s -- --upgrade`；自定义安装路径时追加原路径参数。Linux 服务命令加 sudo，macOS 不加 sudo。
- 重复运行普通安装器会在下载应用包前识别已有安装并提示升级入口。升级失败时显示已完成步骤、备份位置及恢复命令；恢复时请保留一致备份。
