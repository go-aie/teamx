## 已实现

- 会话工具栏和菜单提供环境入口，可固定或取消固定；支持独立宽度、展开、重新连接与多成员环境选择，未配置时显示空态。
- TeamX 服务端根据完整 Room／成员身份选择显式配置的环境，转发 noVNC 核心模块和 VNC WebSocket；环境网关地址、认证 Header、静态目录与 WebSocket 路径独立于 MCP 配置。
- 上游密钥不进入前端响应，TeamX 登录凭据不转发给上游；只开放指定资源路径和画面连接，限制同时最多 8 条流。成员移除、登录过期或退出登录后关闭对应观看连接。
- 默认使用客户端观看模式，缩放画面而不修改远端桌面分辨率；点击接管后等待当前回合自然结束，再开放鼠标和键盘。客户端观看模式不等同于服务端协议只读授权。
- 关闭、切换面板、切换会话或页面暂停时释放连接；仅观看不影响 Agent 任务，正在接管的成员则保持暂停。画面传输不依赖截图文件或截图导出补丁。

## 人工接管与交还

接管由成员 Actor 保存归属和短期租约，先持久暂停后续调度，等待活动回合自然结束；不以取消请求替代远端操作结清。异常执行、Session 阻断、模型应用／轮换中不开放输入；共用同一 VNC 网关的多个有效成员不能接管。等待和接管期间，其他页面不能重新启用或轮换该成员。

完成接管先撤销操作连接并等待退出，阻挡并发迟到的操作连接，再提交一条面向该成员的固定 Room 事件，按接管 ID 去重。只恢复此前已启用且没有更新暂停意图的成员，不补充回合预算、不重放原工具调用。事件不包含输入的账号密码。旧页面失联 20 秒后租约过期；关闭或取消接管不自动恢复，进程重启沿用持久暂停状态。

浏览器支持直接点击、键盘输入；画面内的键盘入口补充移动端输入及显式粘贴，不自动读取系统剪贴板。临时输入完成后清空本地桥接字段。

增量验证包括当前回合等待、其他页面互斥、持久暂停和恢复、更新的手动暂停优先、租约过期、异常执行阻断、完成幂等、输入连接退出围栏，以及共享桌面拒绝接管。全仓 Go 回归（Room 包 351.760 秒）、868 项前端测试和定向 race 通过。

`TestEnvironmentHandoffBrowser` 使用真实 AIO VNC 输入和一次性 HTTP 表单，通过虚构账号实际登录并保留同一浏览器 Cookie，验证默认观看不发送输入、鼠标／键盘及键盘桥接、第二浏览器不能抢占、完成后恢复观看并唤醒受控 Agent。临时标签页测试后关闭。该用例没有真实账号或真实模型，保留这一区分。

当前仅验收传统 AIO 1.11.0；官方 `aio-daemon`、`aio-computer` 镜像迁移时须重新验证网关路径、认证、显示环境和浏览器启动状态。未增加容器自动创建、回收或 DSH 容器化。
