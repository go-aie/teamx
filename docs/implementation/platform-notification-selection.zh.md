## 行为与生效

- 公共 Agent guide、默认助理模板和 usage Skill 的平台导航覆盖连接、通知／工具设置及账号／群／项目选择界面。公共导航经 `componentOptions` 拼入两种输入合同的实际 Instructions，旧模板或自定义角色也能收到，不改用户角色文件。
- 平台 Skill 按任务分流：纯总开关直接短命令，复杂设置读取完整观测版本，真实选择使用已有 selection。纯开关回执无需 connection／selection acknowledge；首次默认和已有恢复共用服务端语义，指导不复制平台默认布尔值。
- “飞书选择群的卡片”“GitLab 项目选择卡片”直接恢复原选择、核对账号并创建组件。组件承担搜索／分页；创建后核对回执与结果订阅、简短反馈即结束本轮。展示卡片本身不授权订阅修改，提交后的续接仍核对原意图、最新请求、准确结果版本与已有配置回执。
- member、get、notifications、tool、status 帮助按子命令展示；通知帮助优先短开关，并列完整定制字段。selection 帮助说明卡片入口与 JSON 输出，未改变选择命令参数或持久化协议。
- Instructions 沿既有 `configDigest` 参与兼容性检查。新 Session 直接生效；存量 Session 通过既有已结清 Session 的受控轮换生效，不修改旧配置指纹、后台历史或角色文件，不要求重建对话。配置、Room 历史与回执保留。

## 可重复验收

新入口 `TestPlatformNotificationSelectionRealDSH` 使用实际生产公共指导和内置默认助理角色；另有独立运行保留无平台导航的旧角色。测试使用真实配置中的默认模型、真实 CLI／HTTP／持久回执和 Chromium，远端平台元数据模拟。只写隔离 Store 和成员配置，不启动采集器、不发送平台消息、不改原安装订阅。

每个平台两次独立运行，覆盖新 Session 和已用 Session 的显式受控轮换、首次纯开启、关闭再开启、原话卡片请求。模型实际创建的同一卡片由浏览器搜索／分页／选择／提交，随后原 Agent 读取并 acknowledge 结果；展示与提交卡片均不得改变订阅。飞书另验证提交后“只接收这个群”的复杂设置意图。断言原 seq、短请求形状、冻结版本、原操作 ID、权威配置、工具绑定隔离、单一结果事件和准确 handled version。

```sh
TEAMX_NOTIFICATION_SELECTION_REAL=1 \
TEAMX_SETTINGS_CONFIG="$PWD/.teamx/config.toml" \
TEAMX_DSH_OUTPUT=/absolute/fresh/output \
go test -tags=e2e ./internal/room -run '^TestPlatformNotificationSelectionRealDSH$' -v -count=1 -timeout=50m
```

`TEAMX_SETTINGS_CONFIG` 支持旧 runtime model 和现行模型目录／凭据引用。产物含实际 Instructions、请求／模型工具轨迹、原回执、最终配置、模拟提供方读取、分场景耗时及桌面／手机截图；失败同样保存。`report.json` 为私有本地证据，应使用全新输出目录。组件可见时间从浏览器导航开始计量，不伪称用户请求到首次可见的精确延迟。

既有 `TestConversationSettingsRealDSH` 与 `TestConversationGitLabSettingsRealDSH` 也改为默认助理角色和实际模型配置，去掉“必须读 Skill／必须走指定协议”的专用验收角色。两者仍保留各自 fixture／真实提供方的独立开关和隔离边界。

飞书旧 Chromium 入口补齐浏览器访问中间件和 Agent CLI 执行绑定，并等待实际搜索响应后分页，避免依赖初始目录或尚未完成的搜索。独立服务装配同步发布真实 runtime catalog，并共享生产更新通道。

浏览器复跑还复现了实际组件竞态：搜索仍在进行时，操作投影刷新会提前启用搜索／加载更多按钮，点击会因内部 busy 状态被忽略。`platform-interactions.mjs` 的投影刷新现在保留搜索期间的按钮禁用状态。新增回归在修复前明确失败，修复后通过；没有改变候选或选择协议。
