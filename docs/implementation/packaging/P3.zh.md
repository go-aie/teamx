# P3：macOS arm64 本地真实验收

> 实施记录：本文保留记录时的范围、结果与缺项，不作为当前操作指南。当前用法见[打包指南](../../../packaging/README.zh.md)及[正式发行操作指南](../../../packaging/releasing.zh.md)。

日期：2026-11-08。按用户本次调整，先验收 macOS arm64 的 core 包：真实 DSH/ACP 与实际浏览器。Git、Scion、GitLab／飞书账号登录、只读命令和连接绑定暂不测试，平台能力由用户另行手动验证。其他目标与下载后 quarantine／签名、干净机器资格检查保留缺项，P4 未实施。

本次范围是本机归档验收，不改变 P0 的四目标交付矩阵，也不把 P2 的 Linux full TLS 库缺项标为已解决。P2 历史记录中“P3 不启动”的顺序约束，本次按用户要求调整为先验证已有的 macOS arm64 归档。

## 可重复入口

```sh
./scripts/package-acceptance.sh dist/<darwin-arm64-core包名>.tar.gz \
  --output-dir "$PWD/.packaging/p3-new-run" \
  --model-config "$PWD/.teamx/config.toml" \
  --env-file "$PWD/.env"
```

`--output-dir` 必须是不存在的目录；每次运行使用新路径。`--model-config` 只提供模型配置及其对应的单个密钥，不沿用其中的 DSH 路径、Room、平台连接或其他环境。兼容性、reasoning 等模型参数完整保留，DSH 固定指向归档内的入口。密钥也可由环境提供，或用 `--env-file /绝对路径/私有.env` 通过包内 Node 读取选定变量。

验证器需要源码检出、Go 与 Node；浏览器检查需要验证机已安装的 Playwright/Chromium。它们是验收机工具，不是发行包运行依赖。服务、CLI 和 DSH 子进程使用隔离 HOME、其他 cwd、受限 PATH、包内 TeamX/Node/DSH。不会在运行时安装依赖或登录业务平台。没有显式模型配置时，真实 DSH 标为 `not_run`，整体退出 2；缺少浏览器也不生成通过结论。

macOS 受限 PATH 显式保留系统 `/usr/bin/sandbox-exec`。真实回合发现隐藏该工具会让 DSH 报 `spawn sandbox-exec ENOENT`，因此已补充为 manifest/随包说明中的系统前提；继续使用 `workspace-write`，不通过切换权限模式消除错误。

## 检查与证据

- 验证最终 tar.gz 的摘要、目标架构、文件／权限／链接和完整运行时，重新执行现有离线 smoke；ACP fixture 仍单独记录。
- 使用独立测试 Room 与真实模型完成私有回合、CLI 工具、显式 Room 发言、运行中前台工具取消、取消后继续、正常关闭，以及同一服务数据重启。
- 重启后发送新的消息，验证原 DSH Session ID、最初的私有记忆和角色标记；只看到 readiness 或没有新输入的 retry 不算 Session 恢复。
- 检查取消工具与 DSH 进程消失、DSH 目录锁释放、Room 状态持久化；收尾失败时不报成功。
- 实际 Chromium 访问归档内的生产页面与后端，创建并进入 Room，检查桌面／窄屏、独立 home、用户配置和模板保留、SIGINT／SIGTERM 端口释放及重启后的 Room。浏览器步骤不发模型 prompt。
- 顶层 `report.json` 绑定归档 SHA-256、manifest、依赖指纹和验证器源文件摘要。归档、包内不可变文件或验证器在运行中变化均使验收失败。

证据保存在私有输出目录：`report.json`、`smoke.json`、`real-dsh/report.json`、服务／测试日志、Session 文件和浏览器截图。该目录可能包含私有模型内容，只保存在已忽略的 `.packaging/`，不加入分发清单或公开记录。

顶层 `status: passed` 只表示报告中明确列出的本地范围全部通过；`release_ready` 始终为 `false`，暂缓项不计为通过。退出 0 表示本次范围通过，退出 2 表示有失败／缺项。源码回归和归档验证分别报告，不将外部 Go 验证器视为包内 TeamX 的替代品。

额外失败样本：模型曾把长命令设为 `run_in_background=true`；该次取消未在结清预算内完成，Room 正确进入 `session_reset_required` 保护状态。旧验收驱动随后的 `member run` 使用现有启用语义创建了新 Session，导致私有记忆检查失败。该报告保留在 `.packaging/p3-darwin-arm64-final/`，不能算原 Session 恢复成功。驱动现已明确要求前台工具，并在继续前拒绝 `session_reset_required`，避免在原 Session 验收中触发重置。本次前台取消的结果不覆盖任意后台作业的取消／恢复。
