## 夹具修复与未决问题

- HumanRead、动作图片与附件的独立 HTTP 组合显式使用已有组件主体上下文。日历绑定实际访问中间件下的测试主体，创建／打开／更新及重启后的旧 epoch 拒绝仍走原 HTTP 接口。
- 两项页面 HTTP 组合使用正式本地访问中间件；Node 请求补上浏览器实际发送的 Origin。DOM EventSource 从实际 `/v1/ui` 响应取得 installation ID 并用于 hello，避免安装身份检查误判断线。生产客户端、服务端检查均保持原样。
