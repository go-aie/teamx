# 在线模型管理与成员切换

2026-11-12 完成[模型配置方案](../MODEL-CONFIGURATION-AND-LIVE-APPLY-PLAN.zh.md)阶段 3。开放范围仅为已经使用托管 `models` 列表的新结构实例；旧数据迁移、删除与替换仍属于阶段 4。

## 实现

- 全局「设置 → 模型」提供新增、编辑、设默认、使用者和操作进度，不依赖当前房间。成员详情提供「使用默认」与各条目的固定引用，展示目标与当前 generation 的实际模型，保留默认和显式选择当前默认两种含义。
- 首次设置和在线编辑共用参数读写逻辑，保留 developer 兼容性的省略／false／true。复用密钥、显式更换、成功／退出清空与私有保存沿用原机制。执行配置变更及实际目标变化先验证文本、固定工具往返和清理；改名及等价引用不发请求、不换 Session。
- `/v1/models`、`/v1/models/change` 和 `/v1/models/operation` 复用管理认证、固定主体、Origin 和执行 token 路由隔离。稳定请求 ID 绑定原输入；异步任务属于服务，浏览器刷新或请求断开不会取消已受理操作。可查询、提交前取消、提交后重试同一目标。
- `model-operations/` 保存提交事实、完整目标身份、选择版本和固定执行快照。网络验证不持有配置／管理锁；发布时再次枚举成员，覆盖验证期间创建的成员，遇到未完成创建预留则拒绝提交。随后持久登记目标并冻结受影响成员的新回合，再原子提交 TOML 并发布内存。
- 门禁只影响新回合，保留用户启用意图；当前回合、工具和平台调用继续完成。执行结束后才进入平台结清，沿用 `prepared → old_closed → completed` 关闭旧 Session、安装携带目标模型和凭据的 Backend；更新本身不额外发起回合。等待期间的显式暂停保持有效，累计用量不清零。
- 成员分别应用，等待或失败不持有配置写槽。同房间／不同房间均保留独立目标；某个 DSH 安装与验证身份不一致时只阻断该成员。没有打开的房间通过本地结清证据和固定 generation 处理，不启动房间或模型。
- 重启先恢复门禁与提交事实；旧 Session 恢复使用自身快照，未完成操作显式重试。进度以 rotation 事实汇总；后续轮换替换 `rotation.json` 前保留原完成记录，避免部分失败操作重试时再次轮换已经完成、甚至已经改选其他模型的成员。
- 配置写入结果不确定时保持门禁，不关闭旧 Session；核对文件与目录持久性后才继续。确定没有提交则解除门禁，原配置继续使用。失败诊断不回传上游原始响应或密钥。
- Workspace 授权比较只排除可变模型引用和选择版本，继续严格比较身份、Workspace、工具与其他配置；待切换期间阻止冲突的 Workspace 操作，不重写历史回执。
- 页面轮询保留编辑草稿及原始预期版本；服务 epoch、成员身份与迟到响应均校验。Key 不进入浏览器存储。共享表单模块加入登录前的精确静态资源白名单，业务 API 仍要求管理认证。

## 验证证据

- 模型切换、快照、Workspace 比较、登录资源的定向组件／集成及 race 检查通过。新增覆盖默认／显式语义、同房间独立目标、闭合房间、等待不提前结清、等待期间暂停与无关维护、部分失败、固定目标重试、重启门禁、提交结果不确定、外部配置冲突、验证期间并发创建及同 ID 防重。
- 专项验证：部分操作中已完成的成员继续改选 C，另一个成员重试 B；前者保留 C 的 generation，完成事实从 rotation 历史读取，不被旧操作覆盖。
- Go 组件与现有 Room 集成检查、前端全部 435 项检查通过。前端新增检查覆盖密钥复用、共享三态表单、默认／显式选项、列表与成员草稿版本保留。
- 真实 Chromium `147.0.7727.15`、托管 DSH `0.2.2-rc.1`、真实服务模型 `deepseek-v4.1-flash-1017`：A Session 完成真实对话后，网页新增并验证 B，刷新继续查询原操作；改默认后生成 B 的固定目标且没有额外模型回合，后续真实对话进入 B 地址。代理记录确认实际请求使用 `max_completion_tokens = 8192`，developer 兼容 false 时无 developer 消息，凭据指纹一致。
- 同一真实浏览器流程固定当前 B 不轮换；默认改回 A 后显式 B 仍保留原 generation；重启、重新登录后继续通过 B 完成真实回复，宿主 `OPENAI_API_KEY` 显式为空。
- 真实流程使用同一个上游模型、不同条目地址和输出参数验证 Backend 替换；没有宣称已覆盖两个不同上游模型或其他 DSH 版本。当前回合等待、部分失败和不确定写入主要由可控故障测试验证。
- 报告与截图：`.local/model-live-20261112-05/`；可复用入口：`scripts/model-live-apply-probe.mjs`。测试只写隔离 home，不改原部署，不调用真实平台业务写操作。
