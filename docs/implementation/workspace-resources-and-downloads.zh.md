# 工作区图片、相对资源与下载实施记录

范围：落实 [工作区文件与预览方案](../WORKSPACE-FILES-AND-PREVIEW-PLAN.zh.md) 的 F3 两个检查点，沿用 F1/F2 的目录来源、消息指纹和文件面板。全部验证在隔离测试目录／Room 中进行，日常部署未修改；真实 DSH／模型生成—交付—修改闭环属于 F4。

## 资源预览

PNG／JPEG／WebP 支持文件面板直接查看、消息文件链接进入、文档内相对图片及原有图片放大交互。服务端依据真实内容检查类型、尺寸和完整解码，限制 16 MiB／2,500 万像素；与消息附件共用两槽解码限制，不创建或改变附件引用。类型伪装、损坏图片和资源超限保留元数据及原因，可在下载上限内下载。

Markdown 文档的相对链接、引用式链接和图片扩展 F2 的同一路径转换函数：只解码一次 URL 转义，以文档所在目录为基准，根内 `..` 可用，越界、协议、查询参数和危险路径拒绝。标题锚点支持中文、URL 转义、纯锚点及跨文档锚点；重复标题分配稳定后缀。文档返回栈保留路径、阅读位置和源码模式，不登记文件历史版本；返回时需要重新读取的文件仍核验原来源。

每篇文档前 20 张本地图片在接近可见区域时自动加载，其余提供点击加载；客户端和服务端均限制并发。远程图片仅显示外链，危险 HTML 仍转义。图片通过同源受约束接口取得 Blob，页面关闭、来源失效、消息清空和会话切换会取消读取、清理图片／放大窗口并回收 URL；迟到响应不能重新安装图片。文件正文、Blob 和令牌不写入本地持久缓存。

## 有界下载

所有不超过 64 MiB 的获准普通文件提供「下载」，文本超出预览上限时也可下载；HTML、SVG、PDF、Office、压缩包和其他二进制只下载。列表和预览的能力上限来自服务端响应，直接浏览及消息入口使用相同接口与来源规则。

`/v1/workspace/files/content` 默认只交付验证过的图片；`download=true` 流式下载。下载保持原文件句柄、初始大小和来源，交付前再次核对文件、Room、原消息及当前目录。已准入的传输不重新解析路径；目录切换、消息清空后新请求拒绝，已开始传输按原句柄有界完成或取消。下载通过浏览器下载管理器跟踪和取消，不在应用内缓冲完整大文件。

所有文件响应均为 `private, no-store`、`nosniff`。图片使用验证后的 MIME 与 `inline`；普通下载固定 `application/octet-stream`，文件名通过标准库构造 `Content-Disposition: attachment`。读取与下载共用四槽队列；请求取消释放槽与句柄。下载总时限 30 秒，显式设置响应写截止时间覆盖托管 HTTP 的默认 15 秒写超时；取消会提前打断阻塞写入，服务关闭沿用现有 HTTP 关闭路径。文件系统本身不可中断的阻塞不在保证范围。

## 验证

最终命令、结果和浏览器场景见 [验证数据](workspace-files/resources-evidence.json)。

前端 824 项测试、相关 Go 测试、定向 race 及实际 HTTP／浏览器验证通过。完整 `go test ./internal/room ./internal/web` 在 534.177 秒后报告 Room 包两项既有架构失败：`TestStaticAssemblySourcesAndCapabilitiesAgree` 的 GitLab Events 装配不一致，以及 `TestInboxAndActionCoreHasNoNativeProviderRules` 中 `actions_target.go` 的飞书规则、`agent_contract.go` 的飞书适配器依赖；Web 包通过。它们与 F1/F2 的已知失败一致，未因此修改对应实现，完整回归不能记为通过。

实际浏览器同时覆盖原生定时器／fetch 装配与 Blob 生命周期。目录应用会切换运行时 epoch，后续读取在操作完成后的新服务身份下复验。最终 F1–F3 浏览器组合的 8 个场景全部通过。

- Go：真实 PNG／JPEG／WebP、类型伪装／损坏／像素与大小上限、特殊文件、保护路径、超限下载、文件替换、固定句柄、交付前来源／消息失效、清空后直接浏览、HTTP 响应头与 Unicode 文件名；网络取消、写超时及服务关闭释放传输和队列。相关附件权限与清空回归同时运行。
- 前端：完整 Node 测试；消息与文档使用同一路径转换、相对基准、编码与锚点、危险 HTML、远程图片规则及既有导航／迟到响应回归。
- 实际 TeamX HTTP／Chromium：多人 Room 和默认助理私信；1600×1000、1000×850、390×850。覆盖直接浏览与消息入口、文档导航／返回、锚点、图片放大、20 张自动预算与显式加载、Markdown／HTML 下载、Blob 清理、内容迟到、生产目录应用／恢复、旧链接失效与消息清空。消息为持久化的可信来源夹具；F2 的独立回归另行覆盖真实 Session host／执行凭据／send 链路，均不代表真实模型验收。
- F1/F2 浏览器回归覆盖默认／外部目录、单聊／多人 Room、旧消息、单请求直达、源码、展开、草稿、焦点与侧栏恢复。
