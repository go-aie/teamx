# 页面返回与来源恢复

手机端与桌面端共用原则：返回用户实际经过的上一处。详情页统一使用「← 返回」，不再通过「返回列表」「返回助理详情」等文案固定目标。

## 路径梳理

| 页面或入口 | 返回行为 |
| --- | --- |
| 对话中的 Agent 头像、姓名、执行提示 | 恢复打开详情前的对话与侧栏状态 |
| 成员列表中的 Agent | 恢复成员列表及阅读位置 |
| 已打开另一成员详情时查看 Agent | 恢复原成员、标签页及阅读位置；Inbox 保留原分页快照 |
| 会话菜单中的会话通知 | 恢复进入前的对话或侧栏状态，不额外进入助理详情 |
| 对话中的平台通知来源、历史来源诊断 | 恢复原对话与侧栏状态 |
| 成员的平台、Inbox 中的通知来源 | 恢复原成员详情、标签页及阅读位置 |
| 通知来源中的管理平台、成员中的模型设置 | 退出全局设置后恢复实际来源 |
| 从成员或对话直接打开平台连接表单 | 表单返回直接退出设置，恢复成员或对话 |
| 设置平台列表中的连接表单 | 返回平台列表，恢复原条目与滚动位置 |
| 设置模型列表中的编辑表单 | 返回模型列表，恢复阅读位置并清除未提交密钥 |
| Workspace 中的管理平台 | 保留 Workspace 表单，退出设置后继续编辑 |
| 时区选择、安全验证、操作确认 | 浏览器返回先退出当前最上层选择或确认 |

## 保留的区别

- 侧栏收起控制显隐；详情返回恢复来源，两者仍是独立操作。
- 设置分类及 Agent 标签页是同级切换，不逐次加入返回层级。
- 设置、Workspace、新建会话等对话框保留关闭按钮；关闭恢复其入口。新建完成、接入后查看目标等明确跳转仍按操作结果进入目标。
- 取消编辑、取消登录、停止接入和确认操作保留各自含义，返回不会触发保存或重新提交。
- 手机端顶部「会话」保留为会话列表入口。

## 实现与验证

来源状态只保存在当前页面内存中，包括焦点、滚动位置和侧栏状态。表单值及操作请求不会写入浏览器 history；返回来源须匹配当前安装、操作人、服务及 Room 实例。来源成员被移除时不恢复旧成员页面。

浏览器返回依据当前可见层级退出；前进不会重新打开表单或重放写操作。页面按钮、Escape 和浏览器返回复用相同的退出处理；保存中的退出限制仍然生效。
