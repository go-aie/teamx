# 桌面／手机共用 Web 体验

2026-11-12。对应[常驻 Server 与 Web Client 方案](../DESKTOP-APPLICATION-ANALYSIS-AND-PLAN.zh.md) W3。代码与自动验证已实施；至少一部真实手机的验收出口尚未完成。

## 已实施

- 沿用原生特性模块和同一套 UI。手机默认聚焦对话，会话、成员、助理详情和 Inbox 按需覆盖展开，并提供返回对话入口；桌面多栏、宽度偏好和快捷键保留。触控手机横屏继续使用紧凑布局。
- 使用动态视口、安全区和局部 VisualViewport 高度／偏移适配。输入框与发送区留在可视区，表单、卡片和弹窗限制宽度／高度；手机字段使用 16px 字体，常用操作提供 44px 触控区域。浏览器缩放保持可用。
- 保留 `isComposing`／229 处理，补齐 composition 生命周期及确认后紧邻 Enter 的保护。现有消息／交互卡片继续复用稳定节点，轮询和新消息不替换正在输入的卡片。
- 增加页面生命周期控制。隐藏、pagehide 和离线时停止新展示请求，包括主刷新、平台登录状态和模型进度；已开始的请求可能结清。恢复前台、pageshow、online 后先等待旧读取结束，再通过受保护入口核对服务和会话。online 本身不表示服务连接成功。
- 离开页面只清除敏感表单输入，不取消 Server 上的授权操作。临时状态读取失败继续查询原操作，不自动重新登录或创建新连接；明确点击取消仍走原取消路径。完整跨页面 OAuth 恢复留在 W4。
- 模型首次设置与在线编辑复用共享表单。白名单持久化非秘密字段、兼容三态和原始预期版本；Key 与含凭据／query 的 Base URL 不写入草稿。版本冲突保留原预期版本，首次设置可明确放弃旧草稿后按当前版本重填；在线编辑可取消后重新编辑。原模型 operation ID 在提交前保存，刷新／重新登录后只查询原操作，不自动创建新操作；未知结果可明确读取进度。列表数据未变化时保留按钮节点／焦点，模型进度轮询也服从页面后台控制。
- 浏览器 Back 优先退出当前弹窗或手机侧栏。历史条目只保存临时界面名称，不写表单、凭据或业务命令；Forward 不重放业务写入。
- 受保护的 `/v1/ui` 与首次设置所用的 `/v1/access/session` 返回 `installation_id`；业务 UI 同时保留已有 `service_epoch`。正式版本根复用 `installation.json` 的实例 ID；独立 home／配置启动在数据目录保存随机 `installation-id`，重启和 token 轮换不更换，损坏时拒绝静默重建。未认证健康接口不公开此身份。
- 草稿按实例、Room instance 和操作者隔离。代际变化后重新读取状态，同实例保留输入；旧实例延迟返回的回执不会写到新实例的草稿。未确认消息保留原身份与消息 ID，只在用户明确重试时提交；设置冲突明确提示其他页面或设备更改，保留本地草稿。

浏览器草稿仍使用当前标签页的 sessionStorage，不是多设备同步。平台／模型密钥不进入草稿或历史；页面刷新后需重新填写尚未提交的密钥。没有离线发送队列、Service Worker、系统推送或新移动站。

## 模型衔接补充

2026-11-12，在源码基线 `baf64e2` 上按主方案第 11.2 节补充。消费模型阶段 4 的[删除、迁移与交付记录](model-deletion-migration-delivery.zh.md)，本次不重做模型服务、Session 轮换或迁移，也未重新验证该记录中的发行归档。

- 首次设置提交响应及随后查询都失败时，保留原请求 ID、非秘密草稿和预期版本，锁定新提交及放弃草稿入口；恢复后只读取服务持有的操作。已保存、仍在初始化的状态继续等待；认证读取确认操作失败或尚未受理后，才允许用户明确重新提交。增加读取进度入口，并隔离提交前发起的迟到读取，避免它解锁结果未知的新提交。
- 模型页仍省略已完成／取消历史，但所有执行中及已提交失败的操作保持可达，不因另一设备／成员完成较新操作而丢失重试入口。重试沿用原操作 ID；不同操作更新时复用未变化的结果节点，保留焦点和展开状态。
- 成员状态图标改为点击展开详情，直接显示目标模型、当前 Session 实际模型、等待／失败信息，并提供原操作重试和模型设置入口。手机查看这些信息不依赖悬停；详情区限制高度并允许局部滚动。
