# 私信、房间与默认助理

私信面向一个 Agent，团队房间让多个角色共同参与。每个会话独立保存消息、成员状态、收件箱、长期规则和工作文件，同名助理或相同团队也不会共享运行状态。

## 选择与创建

首次配置模型后，默认「个人助理」私信会准备好，可以直接发送需求。需要多个角色协作时，点击左侧「＋ → 新建房间」选择团队模板，确认开场消息后发送。

也可以通过「＋ → 新建私信」创建独立的个人助理。手动新建的助理默认暂停，进入详情后启用；创建会话或点击空态建议不会自动发送消息、连接平台或执行任务。

左侧统一展示私信和房间，默认助理置顶，其余按最近消息排序。列表标题旁的下拉箭头可筛选「全部会话／私信／房间」。标签页各自保存查看对象；切换会话或关闭页面不会停止后台执行。手机上从列表进入聊天，通过「助理详情」查看成员设置和活动。

私信标题是对方的显示名称，可以从标题或成员设置改名；团队房间的标题与成员名称分别修改。改名保留上下文、规则、平台绑定和工作文件。

页面会自动显示消息和状态变化。切到后台或离线时暂停实时同步；恢复后补读期间的变化，保留当前草稿和浏览位置。提交结果未确认时只核对原请求，继续发送或重试仍需你的明确操作。

## 参与讨论与查看执行

直接发送目标、约束和补充信息即可。输入 `@` 后按显示名称或内部 ID 搜索成员，同名候选会附带 ID 供区分；选择后会保存准确目标，改名不影响历史提及的归属。

成员保留独立的私有上下文，思考和工具结果不会自动变成公共发言。点击成员查看「活动记录」，了解当前执行和工具调用；成员读完后可以保持沉默。

成员详情还提供「平台」「长期规则」「收件箱」。接入与跟进见[平台通知与跟进](notifications.zh.md)；默认助理可以通过对话[连接飞书](lark.zh.md#通过对话接入)，无需预先绑定平台工具。

## 控制执行与清理会话

| 你要做什么 | 操作与影响 |
| --- | --- |
| 暂停或恢复成员 | 在详情使用「暂停／启用协作」；保留消息、上下文和工作文件。失败后先核对原因，再恢复 |
| 取消当前回合 | 在执行控制中取消，等待状态确认结束；已完成的外部操作不会因此撤销 |
| 重新开始讨论 | 会话菜单「重新开始」；清空公共消息并重置私有上下文，保留工作区及累计用量 |
| 删除会话 | 使用会话删除操作；永久移除该会话的消息、私有上下文和工作区文件 |

默认个人助理可以改名、暂停或重新开始，不能删除；手动新建的私信可以删除。正常重启服务会按原状态恢复，不会自动重新启用你暂停的成员，也不会重放失败或结果未知的任务。

模型私有会话默认每受理 16 回合自动轮换，在下一次正常输入前开始新上下文，无需手动续额。需要手动重置单个成员或排查中断时，见[运行参考](../internal/room/README.zh.md#回合预算与轮换)。

## 未读与提及

会话列表显示未读数，超过 99 条显示 `99+`；房间有未查看提及时另显示「[有人@我]」。自己的消息不计未读，Agent 读取也不影响你的计数。

前台打开聊天且消息成功加载后，普通未读会清除。提及逐条确认：点击成功定位并显示，或自然滚动到可见区域后即视为已查看；仅打开聊天不会清除未查看提及。

聊天右上角优先显示「有人 @我」，点击定位最早未查看的提及；历史较长时会自动分批加载，可以取消，失败后可以继续。查看后移除消息左侧强调线，正文中的 @ 保留颜色。

全部提及查看后，右上角改为「N 条新消息」，用于回看本次打开期间尚未查看的新消息；「以下为新消息」表示本次进入的新旧边界。右下角「回到最新消息」用于返回底部。翻阅历史时保留当前位置，新消息不会强行跳到底部。

电脑与手机连接同一服务时，共享普通打开位置和逐条提及进度，刷新、退出和服务重启后保留。聊天内本次回看提示和滚动位置仅属于当前页面；离开聊天或刷新后不恢复，也不跨端共享。

详情、弹窗、键盘遮挡、失焦和后台期间不会确认被遮挡的消息。同步失败会保留提示，阅读故障不阻断发送。旧版升级后部分普通历史可能重新计入未读，成功打开后清除；升级后请刷新页面。

## 发送图片

在输入框旁点击「+ → 添加图片」选择图片，电脑上也可以直接粘贴截图。可以只发图片，或一起发送文字和多张图片；输入文字后仍可继续添加。图片来自当前浏览器所在设备：手机访问另一台电脑运行的 TeamX 时，选择的是手机相册或文件，不是服务端工作目录。目录按钮仍用于设置 Agent 的工作目录。

手机能否粘贴图片取决于系统和浏览器是否向网页提供图片文件；没有图片粘贴能力时，请使用「添加图片」。取消选择会保留草稿，可分次追加，不会自动发送。

首版支持 PNG、JPEG、WebP，默认每条最多 4 张、单张 2 MiB、合计 4 MiB、单张不超过 16 Mi 像素；服务配置更小时按更小限制执行，添加菜单显示当前数量和大小限制。HEIC／HEIF、GIF、SVG 等请先另存为支持的格式，TeamX 不自动转换或压缩。

图片上传时会显示缩略图和状态；全部就绪后才能发送。上传失败可重试或移除，不能直接跳过失败图片发送其余内容。发送后的图片可点击放大、缩放、旋转或下载。

切换会话会保留各自的草稿，刷新后恢复已上传的图片；尚未完成上传且本地文件已丢失的条目需要重新选择。未发送图片的上传有效期为 24 小时，已发送引用继续保留。发送结果未确认时，使用原请求重试；「放弃重试」会保留可编辑草稿，原消息仍可能已提交，请先核对历史再决定是否重新发送。

## 默认个人助理与恢复

默认助理只在配置就绪后初始化，没有真实输入时不会发起模型回合。启动、打开会话或切换页面都不会重新启用已暂停的助理。

旧版本已经删除的默认实例不会自动复活。页面提供「恢复默认助理（新建会话）」：恢复会创建新的独立会话，不恢复原消息、规则或订阅，也不接管同名手动私信。历史删除尚未结束时，先按提示完成原删除。

个人助理可以梳理需求、协助设置和汇总进展；长期规则、群关注及工具只属于当前成员。

## 私信日历与定时任务

私信支持一次性、每天和每周指定星期的定时任务：在聊天中说明任务和日期时刻，或在标题下的「日历」表单创建。Agent 保存后会返回实际规则和下次执行时间；日历可查看、编辑后续安排、暂停、恢复、取消或跳过下一次。缺少必要信息的任务为待完善，不会执行。保存回执会说明实际时区、日期筛选、首次执行时间和漏跑规则。报告发送中时服务会继续发送，完成后可核实本私信中的报告。任务使用保存时的固定时区；修改系统显示时区不会移动安排。

例如：“每天早上 9 点，检查已确认项目的当前迭代进展，并回复这里。”项目等必要范围明确时直接安排；范围不足时先补齐。安排保存、到点排队、Agent 开始执行和报告公开发布分别显示状态，只有报告发布后才算结果送达。

“每天”包含周末和节假日；“周一至周五”只排除周末，法定假日落在工作周内仍执行；“工作日”按中国大陆法定工作日，包含调休补班，回执会明确口径。工作日历随版本离线提供，目前覆盖 2026、2027 年，详情可查看官方来源；覆盖外阻塞，不按普通星期兜底。重复规则可设结束日期（含当天），跳过某次不会顺延。

每条私信有独立日历；即使 Agent 同名、使用同一角色，安排和报告也只属于创建它的私信。切换到其他会话不移动任务，也不阻止原私信后台执行。关闭浏览器不影响执行，但 TeamX 服务必须运行。正常重启服务后会自动恢复已有日历，无需逐一打开私信；已暂停的 Agent 和任务仍保持暂停。停机或休眠后只补最近一次，且到期不超过一小时；更早周期保留漏跑范围。任务暂停期间不补跑，重复任务恢复从提交后的下一个有效时刻开始，已过时的一次性任务需要先修改时间。Agent 暂停时不会自动启用。失败或结果未核实不会自动重做，报告发布到原私信；暂停正在执行的任务会请求停止对应整个回合，已完成的外部动作无法追回。重启讨论会先暂停任务，清空可见消息保留安排和发送回执。

桌面日历默认周视图，可直接切换按日、周和日程列表，点击日期范围打开月历选择日期。时间轴按分钟定位任务，密集安排可展开，当前时间线随本地时间更新。同刻任务可展开查看；时间点条目不表示占用时长。手机默认按日列表，使用顶部一周日期条切换日期，详情返回后保留日期、滚动位置和聊天草稿。任务管理区可以找到待完善、暂停、远期及已取消任务；待完善任务补齐信息后可保存为活动安排。

新建表单默认填写标题、任务说明、日期时刻和重复方式；重复任务再显示星期与日期筛选。执行时区、结束日期、任务范围和错过后的处理放在「高级设置」，保存前可核对实际时区和补跑规则。缺少时间等信息时可选择「保存为待完善」。

任务详情优先显示时间、内容、状态和最近执行；完整规则、范围与工作日历来源在「执行设置」中查看，历史默认折叠。编辑和暂停／恢复直接可用，跳过单次和取消在「更多」菜单中。编辑只影响后续安排，未修改的范围及规则保持原值；历史保留当时的任务快照。其他标签页提交修改后会同步刷新，编辑时版本冲突会保留草稿，需重新打开核对。取消保留历史；跳过单次仍显示原因，也可隐藏已跳过条目。执行历史按页加载，保留最近 90 天、最多 5,000 条，较早明细可能已清理。

聊天中的「查看日历」和任务来源、报告下的入口可以打开安排；执行历史可返回对应私信报告。消息清理后，可在日历查看保存的结果。查看、预览和跳转都不启动 Agent。当前只支持私信，不支持月视图、拖拽调整、外部日历同步或跨会话代管。持续提醒的配置与实际送达分别核验，见[飞书指南](lark.zh.md)。

会话创建、阅读状态及默认实例的管理接口见[会话接口参考](reference/conversations.zh.md)，实现约束见 [Room 架构](room-architecture.zh.md)，其他入口见[文档目录](README.zh.md)。
